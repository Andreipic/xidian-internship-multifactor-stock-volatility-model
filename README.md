# BYD Stock Price Volatility Analysis and Prediction

Stock price volatility analysis and prediction system for BYD Co., Ltd.
(002594.SZ), built as part of a research internship at Xidian University
(School of Electronic Engineering, supervisor: Professor Ru Zong).

Full write-up: `rapport_final_xidian.pdf` (LaTeX report, ~19 pages).

## Project structure

The pipeline is organized into four phases, matching the report structure,
implemented as three standalone Python scripts (`scripts/`):

| Script | Report phase(s) | What it does |
|---|---|---|
| `01_data_collection.py` | Phase 1 (EDA) + Phase 2 (external factors) | Collects 10 years of BYD OHLCV data and external factors, runs stationarity/FFT analysis and correlation structure, writes `data/byd_all_factors_dataset.csv` |
| `02_model_and_prediction.py` | Phase 3 (denoising + prediction models) | Causal Kalman/wavelet denoising, ACF/PACF check, ARIMA(1,1,1) baseline, multivariate LSTM (raw + bias-corrected), SHAP interpretability (aggregate + LPR/commodities isolation), MC-Dropout vs. conformal prediction intervals |
| `03_robustness_and_risk.py` | Phase 4 (robustness + risk warning) | Volatility regime classification, policy-shock and market-crash stress scenarios, ±5% risk-alert indicator, robustness summary |

```
.
├── data/           # input dataset + Phase 4 robustness table
├── figures/        # all report figures, regenerated on each run
├── logs/           # console output of the last run of each script, regenerated on each run
├── models/         # trained LSTM (.keras), fitted scalers (.pkl), metrics summary
├── scripts/        # 01_data_collection.py, 02_model_and_prediction.py, 03_robustness_and_risk.py
├── requirements.txt
├── SETUP.md        # environment setup + run instructions
└── rapport_final_xidian.pdf
```

This repo previously stored the pipeline as three Jupyter notebooks. These
have been converted to the three standalone scripts above; the scripts
contain the same logic and produce the same figures and results.

## Setup and running

See `SETUP.md` for environment setup (Python 3.10/3.11, `requirements.txt`).

Scripts must be run in order from `scripts/`:

```bash
python 01_data_collection.py       # loads data/byd_all_factors_dataset.csv if present
python 02_model_and_prediction.py  # loads models/*.keras + *.pkl if present
python 03_robustness_and_risk.py   # requires 02_ to have run at least once
```

If the committed data/model files are already present, each script loads
and reproduces the report's results directly rather than re-downloading or
retraining. Scripts 01 and 02 fall back to live data collection / training
if those files are missing (with a printed warning that results will then
differ slightly from the report, due to newer data and retraining
stochasticity).

Each script writes its full console output to `logs/<script_name>.log`,
overwritten on every run -- check there first if a number looks off or a
figure is missing.

## Key results (test set 2023–2025, 704 observations)

| Model | MAPE (%) |
|---|---|
| ARIMA(1,1,1) | 4.94–5.01 |
| Naive (walk-forward) | 6.68–6.78 |
| LSTM, recursive (raw) | 5.19–5.33 |
| LSTM, bias-corrected | **4.70–4.78** |

All values meet the project's <8% MAPE constraint. The small ranges above
reflect minor run-to-run variance (data refresh, floating-point
nondeterminism); see `logs/` for the exact console output of the last run
of each script.

Regime and stress-scenario MAPE (Phase 4, all under 8%):

| Condition | MAPE (%) |
|---|---|
| Calm regime | 3.47–3.54 |
| Normal regime | 5.27–5.34 |
| Volatile regime | 6.75–6.89 |
| Policy shock (5-anchor mean) | 6.07–6.11 |
| Market crash (5-anchor mean) | 7.25–7.63 |

## Figures

All figures cited in the report are regenerated by the three scripts into
`figures/`, including two added after the initial report draft:

- `acf_pacf.png`: ACF/PACF of the differenced closing price, supporting
  the ARIMA(1,1,1) $p=q=1$ specification (Phase 3).
- `fft_return_spectrum.png`: FFT power spectrum of daily returns (Phase
  1), showing no dominant cycle -- included to illustrate the negative
  result described in the text (Section 2.2).

## Reproducibility

- `models/lstm_recursive_corrected.keras`, `models/scaler_X.pkl`,
  `models/scaler_y.pkl`: the trained model and fitted scalers used to
  produce the report's Phase 3/4 results. Scalers are loaded, never
  refit, when the saved model is loaded (refitting would silently
  desynchronize training and inference distributions).
- `data/byd_all_factors_dataset.csv`: the exact dataset used for the
  report. Scripts 01–03 all work offline against these committed files.
- Phases 1 and 2 (`01_data_collection.py`) re-fetch live data from
  `akshare`/`yfinance`/`FRED` when run without the committed CSV, so
  re-running from scratch will reflect more recent market data than the
  report.
